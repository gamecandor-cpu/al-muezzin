# موقع إدارة التطبيق — المؤذن | Muezzin

لوحة تحكم ويب **كاملة في ملف HTML واحد مدمج** (`index.html`)، جاهزة للرفع مباشرة على أي استضافة ويب أو Firebase Hosting، ومربوطة لحظياً بقاعدة بيانات التطبيق (`Firebase Firestore`).

## المميزات المدمجة في `index.html`
- **دفع فوري أو مجدول أو متكرر يومياً**: إرسال إشعارات نصية أو تذكيرات صوتية للمستخدمين في أي وقت تحدده (`HH:mm`).
- **مثبت أو مؤقت**: تثبيت التذكير في التطبيق أو تحديد مدة انتهاء تلقائية بالساعات.
- **التعرف التلقائي على رابط الصوت وتشغيله**: لصق رابط Google Drive أو Dropbox أو أي رابط صوت مباشر (MP3 / M4A / WAV / OGG / AAC)، مع التعرف التلقائي على النوع وتشغيله داخل الموقع قبل دفعه للتطبيق.
- **إحصائيات وبحث وتصفية وتعديل**: متابعة التذكيرات المباشرة وتعديلها أو إيقافها أو حذفها أو إعادة دفعها فوراً.

## الرفع على الاستضافة أو التشغيل محلياً
1. ارفع ملف **`موقع ادارة التطبيق/index.html`** مباشرة إلى استضافتك (أو استخدم `firebase deploy --only hosting`).
2. إذا رفعته على نطاق استضافة خاص بك، أضف اسم النطاق في **Firebase Console → Authentication → Settings → Authorized domains** للمشروع `gen-lang-client-0088673365` لتفعيل تسجيل الدخول عبر Google.
3. للتجربة محلياً:
```bash
node "موقع ادارة التطبيق/start-server.mjs"
# ثم افتح: http://localhost:5050
```
